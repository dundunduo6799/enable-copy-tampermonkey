📄 受保护的文章 复制我试试

欢迎来到「禁止复制演示网站」。和很多文档站、小说站、题库网站一样,这里的文字「看得见、摸不着」:你可以随便读,却很难复制走。

本页一共用了 6 层常见保护:CSS 禁止选中、禁用右键菜单、拦截复制/剪切、掐断「选择开始」事件、屏蔽 Ctrl/⌘ + C 等快捷键、输入框禁止粘贴。你的每一次尝试,都会被下方「实时拦截日志」记录下来。

但网页终究要把文字交给浏览器显示,所以只要几十行油猴脚本,就能把这些限制全部解开。装好脚本、刷新本页,看到顶部横幅变绿,「复制自由」就回来了。

💡 小实验:① 拖选这篇文章 —— 连选都选不中(被 ① CSS 拦住);② 再去拖选下面「6 层保护」的说明文字 —— 能开始选,但立刻被 ④ 掐断(看日志);③ 在页面任意处点右键、按 ⌘/Ctrl + C,也都会留下记录;④ 在下面的输入框里粘贴 —— 会弹「只能录入不能粘贴」。

📝 受保护的输入框 粘贴我试试

🧱 本页启用的 6 层保护

  1. ① CSS 禁止选中user-select: none —— 鼠标根本选不中文章文字
  2. ② 禁用右键菜单拦截 contextmenu —— 右键菜单弹不出来
  3. ③ 拦截复制 / 剪切拦截 copy / cut —— 兜底拦截:即使经浏览器菜单产生了选区再复制,剪贴板也拿不到内容
  4. ④ 拦截选择开始拦截 selectstart —— 刚想选择就被掐断
  5. ⑤ 拦截快捷键Ctrl/⌘ + C、X、A、S 全部失效
  6. ⑥ 拦截粘贴拦截 paste —— 上面的输入框不让粘贴,只能手动打字(很多 OA / 录入系统就是这样)

🗝️ 怎么解锁?(装一个油猴脚本)

  1. 浏览器里装好 篡改猴 Tampermonkey 扩展(Chrome / Edge 商店均可安装)。
  2. 点这个链接:安装「解锁复制」脚本 —— 篡改猴会自动弹出安装页,点「安装」即可。
  3. 回到本页刷新 —— 顶部横幅变成绿色「已解锁」,就成功了 🎉
🔧 备用方法:点浏览器右上角篡改猴图标 → 「添加新脚本」→ 全选删掉模板 → 粘贴 enable-copy.user.js 的完整内容 → 保存(⌘/Ctrl + S)。
📂 直接双击 HTML 文件用 file:// 打开也可以,但要在篡改猴的扩展详情里打开「允许访问文件网址」开关。
⚠️ 上面的安装链接打不开?先在本目录运行 python3 -m http.server 8765 启动演示服务器,或改用「粘贴安装」。装好后,可在篡改猴菜单里随时开关「解锁复制」(按网站分别记忆)。
