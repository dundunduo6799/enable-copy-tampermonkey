# 🔓 解锁复制(Enable Copy & Right-Click)

油猴(Tampermonkey / 篡改猴)用户脚本:解除网页的「禁止复制 / 禁止粘贴」限制,并带一个「自动输入面板」,可以把文字和图片**像手动打字一样**写进网页输入框。

> 最初为超星学习通(Chaoxing)作业答题框编写,同样适用于一般网页。

## ✨ 功能

- **解除复制限制**:恢复文字选中、右键菜单;复制被网站拦截时,自动把选中的内容补写进剪贴板
- **解除粘贴限制**:粘贴被拦时(如「只能录入不能粘贴」),把剪贴板内容当作手动录入写进输入框
- **📋 自动输入面板**:粘贴文字/截图 → 🎯 选目标 → 一键写入,支持:
  - 普通输入框 / 多行文本域 / contenteditable 富文本编辑器
  - **iframe 里的编辑器**(UEditor 等,含 about:blank 沙箱框架)
  - **超星学习通答题框**:直接走编辑器接口写入,粘贴拦截彻底管不着
  - **图片/截图答案**:自动转 dataURL 插入,交作业后不失效
- **开关按网站分别记忆**(在 A 站关闭不影响 B 站)
- 不破坏网站自己的「复制按钮」(copy/cut 采用"营救"而非"吞事件"策略)

## 📦 安装

**方式一:GitHub 一键安装**(推荐)

1. 浏览器装好 [篡改猴 Tampermonkey](https://www.tampermonkey.net/)
2. 打开:<https://raw.githubusercontent.com/dundunduo6799/enable-copy-tampermonkey/main/enable-copy.user.js>
3. 弹出的安装页点「安装」;以后有更新会自动提示

**方式二:Greasy Fork 脚本库**(发布后)

见下方「发布到 Greasy Fork」。

**方式三:手动粘贴**

篡改猴图标 → 添加新脚本 → 清空模板 → 粘贴 `enable-copy.user.js` 全部内容 → ⌘/Ctrl+S 保存

## 🚀 使用

| 场景 | 做法 |
|---|---|
| 复制被拦 | 直接选中复制即可(脚本自动补救);右键菜单恢复 |
| 粘贴被拦 | 输入框里直接 Ctrl+V,提示框无视,内容会自动进去 |
| 实在进不去 | 篡改猴菜单 →「📋 自动输入面板」→ 粘贴内容 → 🎯 点目标框 → ⚡ 一次性输入 |
| 某网站想关闭脚本 | 篡改猴菜单 →「🔓 解锁复制:本站已开启」点击关闭(按网站记忆) |

## 🧪 本地演示

`index.html` 是一个自带的演示网页:启用 6 层「禁止复制/粘贴」保护(含实时拦截日志),装好脚本刷新即可看到全部解锁。

本地预览:

```bash
python3 -m http.server 8765
# 打开 http://localhost:8765/
```
